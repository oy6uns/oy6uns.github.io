# Publication teaser images

Drop teaser images here and reference them from `index.html` / `publications/index.html`.

Replace the placeholder markup:

```html
<span class="pub-thumb is-empty" aria-hidden="true">KDD 2026</span>
```

with:

```html
<a class="pub-thumb" href="LINK_TO_PAPER" target="_blank" rel="noreferrer">
  <img src="assets/teaser/hwang2026maritime.png" alt="" loading="lazy" />
</a>
```

(From `publications/index.html`, the path is `../assets/teaser/...`.)

Recommended: 16:10 aspect ratio, ~960×600 px, PNG or JPEG.
