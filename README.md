# Sungho Bae — Personal Website

A responsive academic portfolio built as a dependency-free static site for GitHub Pages.

## Local preview

Run a local server from the repository root:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

Push the `main` branch and choose **GitHub Actions** under **Settings → Pages → Build and deployment → Source**. The included workflow deploys the site automatically.
